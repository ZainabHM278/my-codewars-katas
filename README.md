# My Codewars Katas

[![Codewars rank](https://www.codewars.com/users/ZainabHM278/badges/large)](https://www.codewars.com/users/ZainabHM278)

My daily problem-solving practice: I try to solve one [Codewars](https://www.codewars.com/users/ZainabHM278) kata every day, in Python. Each solution is pushed here automatically by the CodeHub extension as soon as it passes, so this repo doubles as a log of the habit.

## Why

- **Consistency over intensity.** One small problem a day keeps problem-solving sharp between bigger projects.
- **Python fluency.** Short, focused problems are a quick way to practice string handling, sorting, comprehensions and the standard library.

## How it's organized

Katas are grouped by difficulty ([kyu rank](https://docs.codewars.com/gamification/ranks/)), one folder per kata:

```
7-kyu/
└── square-every-digit/
    ├── README.md              # the problem statement, linked to the kata on Codewars
    └── square-every-digit.py  # my solution
```

Browse [`7-kyu/`](7-kyu) for the full list. New rank folders, like `6-kyu/`, appear as I take on harder katas.
