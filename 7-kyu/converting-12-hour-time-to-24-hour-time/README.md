<h2><a href=https://www.codewars.com/kata/59b0a6da44a4b7080300008a/train/python target="_blank">Converting 12-hour time to 24-hour time</a></h2><h3>7 kyu</h3><p>Converting a 12-hour time like "8:30 am" or "8:30 pm" to 24-hour time (like "0830" or "2030") sounds easy enough, right?  Well, let's see if you can do it!</p><p>You will have to define a function, which will be given an hour (always in the range of 1 to 12, inclusive), a minute (always in the range of 0 to 59, inclusive), and a period (either <strong>a.m.</strong> or <strong>p.m.</strong>) as input.</p><p>Your task is to return a four-digit string that encodes that time in 24-hour time.</p><h3 id="notes">Notes</h3><ul><li>By convention, noon is <code>12:00 pm</code>, and midnight is <code>12:00 am</code>.  </li><li>On 12-hours clock, there is no 0 hour, and time just after midnight is denoted as, for example, <code>12:15 am</code>. On 24-hour clock, this translates to <code>0015</code>.</li></ul>
